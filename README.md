# 🚀 MathLabs Enterprise AI

Plataforma de Machine Learning y analítica financiera para PyMEs y empresas. Permite registrar ingresos, gastos y predecir estadísticas de comportamiento financiero futuro.

## 🛠️ Tecnologías utilizadas

* **Backend:** Python + FastAPI
* **Base de Datos:** PostgreSQL (Neon.tech en la nube)
* **Machine Learning & Datos:** Scikit-Learn, Pandas, NumPy
* **ORM:** SQLAlchemy
